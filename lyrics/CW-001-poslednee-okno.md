# CW-001 · Последнее окно

## Текст

```
в двенадцатиэтажке напротив гаснут окна,
одно горит — я знаю чьё, но молчу.
ветер гоняет пакет по пустой площадке,
качели скрипят, хотя на них никого.

я допиваю чай, холодный, как подъезд,
ставлю кружку на подоконник. считаю:
раз. два. три. и последнее окно гаснет.
теперь везде темно поровну. иду спать.
```

## Примечание

Синтетический текст, написанный для репозитория (права чистые, как в золотом корпусе). Живая мишень блокирующего прогона линтера (issue #14): обязан проходить sweep без флагов. Механизм осознанных исключений — `lint_exempt` + `lint_exempt_note` во front-matter.
