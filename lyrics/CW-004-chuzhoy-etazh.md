# CW-004 · Чужой этаж

## Текст

```
лифт открылся на чужом этаже, третьем,
здесь пахнет краской и чужими щами.
та же плитка, тот же глазок, тот же коврик,
только за дверью смеются не мои.

я постоял, послушал, как чайник
свистит на чужой кухне, и пошёл вниз
по лестнице — лифт больше не вызывал:
мало ли, вдруг откроется ещё не там.
```

## Примечание

Синтетический текст, написанный для репозитория (права чистые, как в золотом корпусе). Живая мишень блокирующего прогона линтера (issue #14): обязан проходить sweep без флагов. Первая часть диптиха с CW-013. Механизм осознанных исключений — `lint_exempt` + `lint_exempt_note` во front-matter.
