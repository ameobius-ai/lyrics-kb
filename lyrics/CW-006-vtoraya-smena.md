# CW-006 · Вторая смена

## Текст

```
вторая смена начинается в восемь,
когда первые автобусы ещё пустые.
я запираю дверь, кот остаётся дома,
он знает расписание лучше диспетчера.

цех гудит до четырёх, потом тише,
потом совсем тихо, и слышно вентилятор.
в полночь я иду мимо тёмных витрин,
и моя вторая смена становится первой.
```

## Примечание

Синтетический текст, написанный для репозитория (права чистые, как в золотом корпусе). Живая мишень блокирующего прогона линтера (issue #14): обязан проходить sweep без флагов. Механизм осознанных исключений — `lint_exempt` + `lint_exempt_note` во front-matter.
