# CW-009 · Дневной свет

## Текст

```
дневной свет лампы мигает над столом,
стакан мигает в ответ, тень на обоях.
я перебираю болты в жестяной банке,
нужен один — самый маленький, с прорезью.

за стеной телевизор говорит беззвучно,
сосед старый, звук ему не нужен.
я нахожу болт. вкручиваю. полка держит.
дневной свет больше не мигает. всё.
```

## Примечание

Синтетический текст, написанный для репозитория (права чистые, как в золотом корпусе). Живая мишень блокирующего прогона линтера (issue #14): обязан проходить sweep без флагов. Контрольная граница: «дневной свет» — тип лампы, буквальная деталь, а не binary_light_dark-рамка (именно случай `frame_check: true`, почему флаг не механизируется). Механизм осознанных исключений — `lint_exempt` + `lint_exempt_note` во front-matter.
