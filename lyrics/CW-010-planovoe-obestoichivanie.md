# CW-010 · Плановое обесточивание

## Текст

```
раз — это тьма.
два — это тьма.
три — это тьма.
раз — это тьма.
два — это тьма.
три — это тьма.
раз — это тьма.
два — это тьма.
три — это тьма.
раз — это тьма.
два — это тьма.
три — это тьма.
```

## Примечание

Синтетический текст, написанный для репозитория (права чистые, как в золотом корпусе). Вторая живая проверка механизма исключений (после MC-002): 12 строк по 4 слога, дисперсия 0 — uniform_line_length обязан стрельнуть и быть снятым осознанным исключением с причиной. Advisory parallel_shift_candidate может сработать на почти-идентичных блоках — ожидаемо, не блокирует. Если парсинг исключений или сам детектор сломается, блокирующий sweep упадёт — постоянный регрессионный тест обоих.
