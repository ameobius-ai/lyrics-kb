# CW-012 · Три цифры

## Текст

```
на вагоне мелом три цифры: семь-ноль-два,
кто-то вывел рукой, ветром, не знаю.
я вижу их каждое утро из окна,
и каждое утро они на миллиметр ниже.

дворник говорит, это дети, мелом по вагону.
я согласен. но замеряю каждое утро:
семь-ноль-два ползут вниз, к земле,
как вода, которой нет. как счёт, которому нет конца.
```

## Примечание

Синтетический текст, написанный для репозитория (права чистые, как в золотом корпусе). Живая мишень блокирующего прогона линтера (issue #14): обязан проходить sweep без флагов. Контрольная граница: «не знаю» — «знаю» нет в закрытом списке denial-глаголов, флаг не стреляет. Механизм осознанных исключений — `lint_exempt` + `lint_exempt_note` во front-matter.
