# CW-013 · Чужой этаж (II)

## Текст

```
я опять вышел на чужом этаже, третьем,
теперь уже специально. хочу понять,
почему за этой дверью смеются чаще,
почему коврик здесь прямее, чем мой.

дверь открылась. женщина с миской для кота
посмотрела спокойно, без вопроса.
я сказал: извините, этажом ошибся.
она кивнула. кот вышел и пошёл со мной.
```

## Примечание

Синтетический текст, написанный для репозитория (права чистые, как в золотом корпусе). Живая мишень блокирующего прогона линтера (issue #14): обязан проходить sweep без флагов. Вторая часть диптиха с CW-004. Контрольная граница: строки 2–4 («хочу понять, почему…») — вопросы не оформлены знаком «?» и не получают ответа-коннектива, hypophora не стреляет. Механизм осознанных исключений — `lint_exempt` + `lint_exempt_note` во front-matter.
