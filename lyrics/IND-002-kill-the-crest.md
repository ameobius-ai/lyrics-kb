# IND-002 · Kill the crest

## Текст

```
срежь гребень волны, пока она не встала,
пока барабанщик считает вслух до четырёх.
у нас полторы минуты на всё про всё,
и педаль дилея греется, как утюг.

на репетиции кто-то опять забыл шнур,
поём в холодный микрофон, без эффектов.
и знаешь, так даже лучше: голый голос
держит стенку лучше любых пресетов.
```

## Примечание

Синтетический текст, написанный для репозитория (права чистые, как в золотом корпусе). Живая мишень блокирующего прогона линтера (issue #14): обязан проходить sweep без флагов. Механизм осознанных исключений — `lint_exempt` + `lint_exempt_note` во front-matter.
