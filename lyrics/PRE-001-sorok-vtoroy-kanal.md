# PRE-001 · Сорок второй канал

## Текст

```
сорок второй канал не ловит ничего —
на экране снег, а в снегу кто-то есть.
ты говоришь: выключи, ложись, темно.
я кручу ручку дальше. там, за помехами, весть.

антенна на балконе ржавая, как гвоздь,
сосед за стенкой стучит по батарее.
я держу кулак на кнопке громкости:
вдруг позовут — а я не расслышу, не успею.
```

## Примечание

Синтетический текст, написанный для репозитория (права чистые, как в золотом корпусе). Служит живой мишенью блокирующего прогона линтера (issue #14): обязан проходить sweep без флагов. Если осознанный приём когда-либо потребует флага, он оформляется через `lint_exempt` + `lint_exempt_note` во front-matter — голое исключение без причины само является hard-fail.
