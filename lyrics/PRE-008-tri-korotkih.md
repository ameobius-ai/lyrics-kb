# PRE-008 · Три коротких

## Текст

```
три коротких — и снова три коротких,
линия занята, как вечером вокзал.
я вешаю трубку, считаю до десяти,
набираю снова. три коротких. опять.

может, ты говоришь с кем-то важным,
может, трубка лежит на столе, как всегда.
таксофонная будка пахнет табаком,
и дождь по стеклу пишет свои строки.
```

## Примечание

Синтетический текст, написанный для репозитория (права чистые, как в золотом корпусе). Живая мишень блокирующего прогона линтера (issue #14): обязан проходить sweep без флагов. Рефрен «три коротких» с вариациями — живой parallel_no_shift (накопление, не чеклист); advisory parallel_shift_candidate может сработать — это ожидаемо и не блокирует. Механизм осознанных исключений — `lint_exempt` + `lint_exempt_note` во front-matter.
