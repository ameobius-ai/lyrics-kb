# lyrics/ — живые тексты песен

Реальные тексты треков, по одному файлу на кейс-карточку. Две функции:

1. **FP-оракул детектора**: блокирующий шаг CI прогоняет `scripts/lint_patterns.py` по всем файлам этой директории. Любой новый флаг, дающий ложное срабатывание на живом тексте, роняет CI (issue #14).
2. **Калибровочная выборка**: пороги статистических проверок (uniform_line_length и будущие) замеряются на этих текстах, а не угадываются — см. комментарий над `UNIFORM_MIN_LINES` в `lint_patterns.py`.

Права: только синтетические/собственные тексты (тот же принцип, что в золотом корпусе).

## Формат файла

    ---
    id: PRE-001
    title: Сорок второй канал
    case: cases/PRE-001-sorok-vtoroy-kanal.md
    lane: pre-cyberpunk
    ---

    # PRE-001 · Сорок второй канал

    ## Текст

        <текст песни — линтится только этот fenced-блок>

    ## Примечание

    <свободный текст — НЕ линтится>

(В реальном файле `## Текст` — это markdown-fence \`\`\`, здесь отступы, чтобы не ломать рендеринг.)

- Линтер извлекает только fenced-блок под `## Текст`; проза, front-matter и примечания не свипятся (целфайл-свип документации давал ложные `chorus_checklist` hard-fail в ранней CI-настройке — не повторять).
- `validate.py` требует у каждого файла: поля `id:`/`title:`/`case:`, наличие блока `## Текст`, существование файла-цели из `case:`.
- `README.md` этой директории из sweep исключён (см. workflow) — здесь могут быть примеры штампов.

## Осознанные приёмы: lint_exempt

Если текст сознательно содержит флагируемый приём (осознанная банальная рифма G-13, длинная мантра-рефрен под uniform_line_length и т.п.), он оформляется во front-matter:

    lint_exempt: [banal_rhyme]
    lint_exempt_note: осознанная поппанк-рамка, скидка осознанности на уровне скоринга (P3 = 0.3)

Исключение без непустого `lint_exempt_note` — само hard-fail (`lint_exempt_without_note`, вес 2.0): механизм не может молча заглушить детектор.

## Чек-лист добавления трека

1. Файл `lyrics/<ID>-<slug>.md`; `case:` указывает на существующую карточку в `cases/`.
2. Блок `## Текст` с fenced-блоком; текст внутри.
3. Локальный прогон: `python3 scripts/lint_patterns.py lyrics/<файл>` — ноль флагов (или оформленный exempt с причиной).
4. CI дальше сам: encoding guard → validate.py → self-test (золотой корпус) → блокирующий sweep.
