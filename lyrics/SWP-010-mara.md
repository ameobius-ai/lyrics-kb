# SWP-010 · Мара

## Текст

```
за осокой вода стоит чёрная, как смола,
кто-то зовёт по имени — не откликаюсь.
мара вышивает по кувшинкам крестиком,
и каждый крестик — чья-то колдобина.

я знаю: отмель заканчивается на третьем шаге,
кочки держат, если идти не торопясь.
она не сердится, она просто считает шаги.
я считаю тоже. семь. восемь. берег.
```

## Примечание

Синтетический текст, написанный для репозитория (права чистые, как в золотом корпусе). Живая мишень блокирующего прогона линтера (issue #14): обязан проходить sweep без флагов. Контрольные границы: болотный сеттинг без genre_autopilot (нет «тумана над рекой»/«ворона»/«древнего леса»), «она не сердится, она просто считает» — не формула not_x_but_y (нет «не просто» + эха копулы). Механизм осознанных исключений — `lint_exempt` + `lint_exempt_note` во front-matter.
