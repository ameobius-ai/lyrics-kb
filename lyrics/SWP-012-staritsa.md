# SWP-012 · Старица

## Текст

```
старица — это река, которая отстала,
так бабка говорит, и плюёт через плечо.
вода в ней тёплая, гниловатая, в ряске,
жерех старой реки доживает в ней века.

я хожу к ней по сухому руслу, между ив,
здесь когда-то несло баржи с кирпичом.
теперь несёт только ряску и мальчишек,
и меня — если ступать по корням, боком.
```

## Примечание

Синтетический текст, написанный для репозитория (права чистые, как в золотом корпусе). Живая мишень блокирующего прогона линтера (issue #14): обязан проходить sweep без флагов. Контрольная граница: «старица — это река, которая отстала» — не формула not_x_but_y (определение без «не просто» и без эха копулы). Механизм осознанных исключений — `lint_exempt` + `lint_exempt_note` во front-matter.
