# SWP-014 · Морошка

## Текст

```
за морошкой ходим на дальний мох,
где дорога кончается колдобиной.
отец несёт две жестяных кружки,
одну без ручки — ту, что поменьше.

мох глотает сапог по самую пятку,
комары пишут по рукам свои ведомости.
отец не смахивает: заняты обе руки,
и я терплю, раз он терпит.

на середине брода стоит ржавый бидон,
кто-то оставил ещё до отца.
мы не трогаем. здесь так заведено:
чужое на болоте дольше своего.

к вечеру кружки полные, спины мокрые,
обратно идём по своим же следам.
дома бабка перебирает ягоду на столе:
гнилая в таз, живая в банку.
```

## Примечание

Синтетический текст, написанный для репозитория (права чистые, как в золотом корпусе). Первая длинная форма болотного лейна (16 строк): FP-мишень для uniform_line_length и simile_chain на другом словаре, чем coldwave (двухрегистровая лексика быт+миф, сортировка ягоды как финальное действие). Контрольные границы: «отец не смахивает» / «мы не трогаем» — не denial (нет «я не» + глагола из списка); болотный сеттинг без единого genre_autopilot-маркера (§8). Механизм осознанных исключений — `lint_exempt` + `lint_exempt_note` во front-matter.
