> Автор: Blake Crosley, обновление 2026-07-25. Сохранено: 2026-08-04.

## Три системы контроля (не одна)

1. **Prompt text** — жанр, настроение, инструменты, вокал, подача в Style поле
2. **Metatags** — структура в Lyrics поле: `[Verse]`, `[Chorus]`, `[Bridge]`
3. **Creative Sliders** — Weirdness / Style Influence / Audio Influence

Мастерство всех трёх отделяет «интересная нейромузыка» от «трек, который я выпущу».

## Style поле: формула и сладкая зона

```
[Genre] [Subgenre], [Tempo/Energy], [Key instruments], [Vocal style], [Production], [Mood]
```

- **Сладкая зона: 4–7 дескрипторов.** Меньше 4 — Suno сам заполняет пустоты дефолтами (радио-поп). Больше 7 — дескрипторы конкурируют, результат «грязный компромисс» (например «детройт 60-х» дерётся со «145 BPM»).
- **BPM — приблизительный**, не метроном. «127 BPM» = ориентир.
- **Не работает в Style:** имена артистов («Sounds like Adele» — ненадёжно/фильтруется → описательно: «powerful female vocal, piano-driven pop ballad»), технические микс-термины («sidechain compression on the kick» — игнор), негативные инструкции («no drums» — ненадёжно).
- **Негатив → поле Exclude** в Advanced Options. Это официальный способ убрать инструменты.
- **Порядок жанров важен:** жанр №2 деприоритизируется — главный жанр ставь первым.

## Metatags: что где живёт

- **Meta tags** → Lyrics поле, в квадратных скобках. Управляют структурой и секциями.
- **Style tags** → Style поле, без скобок. Управляют характером звука.
- Теги case-insensitive: `[VERSE]` = `[Verse]`.
- **Словарь тегов в V5.5 не менялся** (март 2026 добавил Voices/Custom Models/My Taste, но не теги).

| Категория | Теги |
|---|---|
| Структура | `[Intro]`, `[Verse 1]`, `[Pre-Chorus]`, `[Chorus]`, `[Bridge]`, `[Outro]`, `[End]` |
| Инструментал | `[Instrumental]`, `[Instrumental Break]`, `[Guitar Solo]`, `[Piano Solo]`, `[Synth Solo]` |
| Вокал | `[Male Vocal]`, `[Female Vocal]`, `[Choir]`, `[Harmony]`, `[Rap]`, `[Whisper]`, `[Spoken Word]` |
| Динамика/продакшен | `[Fade In]`, `[Fade Out]`, `[Crescendo]`, `[Silence]`, `[Key Change]`, `[Tempo: slow]` |
| Параметризованные | `[Verse: whispered vocals, acoustic guitar only]`, `[Chorus: full band, soaring vocals]` |

Параметризованные теги = DAW-уровень контроля через текст. `[Tag: descriptors]` — контроль секции на лету.

## Правда про `[no vocals]`

**Отдельного тега нет.** «no vocals» в Style поле ненадёжно. Рабочий способ:
1. Toggle **Instrumental** в Custom Mode
2. `[Instrumental]` в Lyrics (или `[Instrumental Break]` для безвокальной секции внутри трека с вокалом)
3. `vocals` в поле **Exclude** (Advanced Options)

## Creative Sliders

| Slider | Лево | Центр | Право |
|---|---|---|---|
| Weirdness | conventional | balanced | experimental |
| Style Influence | loose interpretation | default | strict adherence |
| Audio Influence | minimal reference | balanced | strong reference |

- Weirdness высоко + конкурирующие дескрипторы = «песня ни на что не похожа».
- My Taste (v5.5) **не переопределяет явные теги** — он бьёт по дефолтам при недозаданном промпте.

## Стемы (ремастер 11.06.2026, три метода)

1. **Split from Mix** — все тарифы. Вытащить любой инструмент/голос → 2 стема: цель + остальное. Кавер/караоке/сэмпл одного инструмента.
2. **Auto Split** — Pro/Premier. Классический сплит на **12 категорий**: vocals, drums, bass, guitar, keys/piano, synths, strings, brass, woodwinds и т.д.
3. **Advanced Split** — Premier. Из ~100 инструментов выбираешь сам, кастомный набор стемов.

- Отличие от RX/Demucs: Suno работает не с готовым миксом — делит внутренние дорожки (чище).
- **Блед между стемами есть**, особенно у близких по частотам инструментов. В V5 разделение заметно улучшилось.
- Экспорт: MP3 (шаринг/стриминг) и WAV (DAW/мастеринг).

## Suno Studio и MILO-1080

- **Studio DAW** (в браузере): быстрые фиксы (громкость, mute стема, варианты аранжировки). Для полного микса/мастеринга → экспорт в DAW.
- Studio 1.2 (фев 2026): Remove FX, Warp Markers + Quantize, Alternates, time signature в гриде/метрономе.
- **MILO-1080** (март 2026): 16-track step sequencer + synth designer: text-to-sound сэмплы, библиотека треков Suno, встроенный синт, MIDI in/out.
- **Размерность времени — это поверхность редактирования, не тег генерации.** 3/4, 6/8 поддерживаются в гриде Studio, но тега для этого нет.

## Траблшутинг (быстрые ответы)

| Проблема | Причина | Фикс |
|---|---|---|
| Звучит не как промпт | конкурирующие дескрипторы / Weirdness высоко | 4–5 дескрипторов, Weirdness ниже |
| Роботический вокал | v4.5 на free tier | Pro → v5 вокал |
| Трек обрывается | нет `[Outro]` | добавить `[Outro]` / `[End]` |
| Трек тянется после финала | Suno добивает до макс. длины | `[End]` после последней секции |
| Доминирует не тот жанр | жанр №2 деприоритизирован | главный жанр первым в Style |
| Теги поются как лирика | синтаксис/опечатка | тег строго `[Tag]`, квадратные скобки |
| Вокал нестабилен между секциями | нет Persona Voice | Persona Voices |
| Экстенд не совпадает с оригиналом | слишком много генераций между ними | экстендить от последней версии, не от оригинала |
| Вокал-артефакты в инструментале | дескрипторы подразумевают вокал | явно Instrumental toggle + `[Instrumental]` |

Чек-лист перед тратой кредитов: жанр конкретный (не «rock», а «indie rock»/«post-punk»), вокал описан (или Instrumental on), метатеги задают структуру (минимум Verse/Chorus/Outro), 4–7 дескрипторов, настроение явное (без него Suno дефолтит в upbeat).

## Промпт-чек-лист генерации

Цикл «идея → выбор → рефайн → экстенд → редактор → экспорт» обычно **50–100 кредитов на полированный трек**. Итерируй, не молись на один шот.

## API

Официального публичного API у Suno нет (Chirp API исторический, не берёт новых). Wrappers типа gcui-art/suno-api — неофициальные, могут сломаться. Для программной генерации: Stable Audio (официальный API) / Replicate.

## Правовое (кратко)

- Pro/Premier: коммерция разрешена, 100% дохода твоё, роялти Suno не требует.
- UMG v. Suno: dispositive motions due **09.04.2027**.
- Warner Music: партнёрство (ноя 2025), Suno купил Songkick.
- Утечка исходников 2023-24 (июль 2026) документирует скрейпинг YouTube Music (2M+ клипов), Genius, Deezer и др.
- Бреч 55.3M аккаунтов (ноя 2025, добавлено в HIBP июль 2026).
- Практика: не реплицируй конкретные песни, добавляй человеческое творчество (своя лирика, живые инструменты поверх стемов, решения в DAW), документируй процесс.

## Полезные детали из гайда

- Free tier: 50 кредитов/день (~10 песен = 5 батчей по 2 трека).
- Кредиты не ролловерятся, но докупленные топ-апы не сгорают, пока подписка активна.
- Duration slider (веб, v5.5, 20.07.2026) — длина до генерации.
- Web Lyrics Editor (июль 2026): Lyricist (профиль, сохраняет стиль письма), NL-правки («make this line funnier»), рифмы/альтернативные фразы, структура песни кликом, фуллскрин с автосейвом.
- Поле Title почти не влияет на музыку — только метаданные/библиотека.
