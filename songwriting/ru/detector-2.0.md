### 25.27 Жанровые white-list исключения

Перед флагованием детектор сверяется с white-list жанра (живёт в жанровом плейбуке). Совпадение → флаг не ставится И не триггерит hard-fail.

**Фолк-хоррор:** `truncation` не флаг в причетной секции при наличии следа события · `parallel_no_shift` не флаг для припева-формулы, если заменяемое слово копит смысл.

**Критерий умолчания (vague_deixis vs приём):** неопределённость легальна, если в соседних 1–2 строках есть конкретный СЛЕД события (можно сфотографировать).

```
OK:  "будто кто-то позвал" + "к пруду протоптано. и не мной"
BAD: "что-то большее ждало нас" (следа нет) → флаг остаётся
```

White-list не глобальный — только жанровый.

### Hard-fail

Любой флаг веса **2.0** (`tech_metaphor`, `chorus_checklist`, `truncation`) → вердикт максимум SUSPECT (cap 6.9), даже при высоком score.

### Почему не перплексия

Статистические детекторы дают ложные срабатывания на канонических текстах и не работают на коротких формах. Наш детектор — паттерновый: ловим конкретные привычки моделей.

| genre_autopilot | «неон» → «вывеска ломбарда мигает через штору» · «город спит» → «окна гаснут по стояку, наше — последнее» |
| vague_deixis | «всё это было не зря» → «эти три зимы были не зря» или вырезать |

## 3. Функция оценки 2.0

### Новые параметры

- **P11 singability** — открытые гласные на длинных нотах, нет кластеров согласных в драйвовых местах.
  *Для полуречитатива* (говорной дольник, chant, half-spoken) оцениваем не гласные, а: удары ложатся на сетку без втискивания · нет кластеров >3 согласных на стыках · точки дыхания каждые 1–2 строки.
- **P12 cohesion** — интро/бридж/аутро перекликаются, образ-якорь копит смысл, песня читается как одно высказывание.

### REPAIR-приоритизация

```
priority(fix) = вес_флага × лёгкость_правки
  лёгкость: 1.0 = точечная замена слова
            0.5 = переписать строку
            0.25 = переписать строфу
Чинить сверху вниз. Максимум 3 итерации.

КОНФЛИКТ-ЧЕК: после каждой правки — повторный прогон детектора
  по затронутой строфе. Если fix поднял новый флаг с весом >=
  веса починенного → откат, альтернативный fix.
```
