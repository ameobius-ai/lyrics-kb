# Сонграйтинг-плейбук: болотный фолк-электроник / нечисть от первого лица (RU)

Зеркало Notion-страницы «Сонграйтинг-плейбук болотный фолк-электроник» (раздел «Плейбуки и Suno-пакеты»). Источник правды — там.

**Чем полоса НЕ является.** Это не дубль фолк-хоррора. Там — голос свидетеля/причитающего, быт + миф, акустический дарк-фолк. Здесь — **голос самой нечисти**, минимализм, электронный сырой саунд. Оптика перевёрнута: рассказывает тот, к кому приходят.

## 1. Вайб и рамка жанра

- Формула вайба: **тишина + вода + договор**. Нечисть не охотится — она ждёт и принимает плату. Вся драматургия — обмен: монета, кольцо, шаг с берега.
- Эмоциональный регистр: спокойная власть + тоска по теплу. Запрещено: злодейский пафос, хоррор-нагнетание, оправдания.
- Жуть делается умолчанием: жертва никогда не показана, только следы (след на песке, кольцо на дне).
- Референсы: былички и заговоры (Афанасьев), Клюев, Шварц (юродская мистика); из сцены — бестиарий ATL, плоть Хаски, индустриальная подача Shortparis.

## 2. Голос жанра: нечисть от первого лица

- **Хозяин территории** — базовый голос: говорит тихо, констатирует, не угрожает. Угроза — в спокойствии («я не зову — я жду»).
- Правила голоса: логика обмена вместо морали; знание правил, которые люди забыли; одна строка тоски по человеческому на текст — обязательна, иначе картон.
- Запрещено: крипипаста-нарратор («я древнее зло»), декларации силы, объяснение своей природы. Хозяин не представляется — его имя знает припев.

## 3. Лексика: два словаря + предмет-платёж

```
СЛОВАРЬ ВОДА/БОЛОТО: ил, камыш, ряска, топь, коряга, омут, тина,
  осока, плёс, мель, заводь, ледостав
СЛОВАРЬ ДОГОВОР/ОБРЯД: монета, кольцо, крест, помин, зарок, откуп,
  оберег, некрещёный, подаяние
БЫТ-ЯКОРЬ (современный след человека): поплавок, леска, фонарик,
  резиновые сапоги, термос, мостки, бетонная труба
ПРАВИЛО: в каждой строфе — вода + предмет-платёж ИЛИ быт-якорь.
  Жанр без обмена = пейзажная лирика. Без быта — сказка-косплей.
ЗАПРЕЩЕНО (лубок): «тёмные силы», «древнее зло», «зов бездны»,
  «души утопленников» без предметного заземления
```

## 4. Просодия и метрика

- Говорной дольник, 3–4 удара на строку. Строки короткие — болото не спешит.
- Пауза — часть метра: точка внутри строки легальна и желательна.
- Припев — формула зова: повтор имени + заговорная конструкция. Формульность легальна, но заменяемое слово копит смысл.
- P11: припевные окончания на гулкие гласные о/у — подводный резонанс, под низкий chant.

## 5. Рифма

- База — ассонанс на о/у/а; точная рифма — дозированно, как удар.
- Безрифменная строка легальна как жест — но не больше одной на строфу.
- Запрещено: глагольные пары без компенсации; затасканные пары вода/беда, дно/темно.

## 6. Структура

- Короткие формы легальны: 2:00–2:40, куплет 4 строки, припев-формула 4 строки.
- Бридж — инструментальная яма (drip only): тишина прописывается как полноценная секция, не переход.
- Финал: цикл или открытая дверь. Запрещено: развязка, мораль, показанная жертва.

## 7. Образность: механика обмена

```
МЕХАНИКА: каждый образ — либо СЛЕД ЧЕЛОВЕКА (монета в ил,
  след на песке, поплавок), либо ОТВЕТ ВОДЫ (ил в зубах,
  камыш считает шаги)
ПРИМЕРЫ МИФОЛОГЕМ:

  поплавок без рыбака = флаг смены владельца
  ледостав = закрытие границы на зиму
ПРАВИЛО: мифологема работает только на документальной фактуре —
  предмет можно сфотографировать
```

## 9. Анти-слоп чек-лист жанра

- [ ] Голос — хозяин без пафоса: ни одной декларации силы
- [ ] В тексте есть обмен/договор (предмет-платёж назван)
- [ ] Жертва не показана — только следы
- [ ] Минимум одна строка тоски/нежности внутри жути
- [ ] В каждой строфе: словарь воды + предмет-платёж или быт-якорь
- [ ] Припев-формула копит смысл между повторами
- [ ] Нет лубка и крипипасты (см. §8)
- [ ] Тишина прописана в структуре (инструментальные секции с тегами)
- [ ] Прогнано через Детектор 2.0; веса — профиль «фолк-хоррор»
- [ ] White-list: parallel_no_shift в припеве-формуле не флагуется; truncation в заговорных секциях легален

## 12. Внешняя сверка (2026-08-01)

Разовая сверка по фольклорным источникам и сцене. Вывод: механика лейна укоренена в реальных фольклорных жанрах — это сильнее любых сцен-референсов. Правила не меняются.

- **Быличка / бывальщина — документированные жанры русского фольклора** (рассказы о встрече с персонажами демонологии, свидетель от первого лица, бытовые подробности для достоверности). Подтверждает и сам цикл форм ГАТЬ (колыбельная, считалочка, причитание, быличка), и выбор жанра финала.
- **Каноническая механика — та же, что наша.** Классическая быличка (сб. Левкиевской): нарушение правила + нечисть говорит буднично + ноль gore + жертва только следом. Наша «честная механика обмена» и «жертва не показана» — не выдумка полосы, а жанровая структура фольклора.
- **IC3PEAK** — подтверждение вокального канона: шёпот и частушечная речитативность в куплетах, певучесть в бриджах/припевах. **Гард:** их тематика — социально-политический протест; референс по подаче, не по темам. Полоса остаётся в мифе.
- **Сцена существует:** Black Mara (Новосибирск) — drone / dark ambient / ritual с этно-инструментами; британский Folk Horror Revival — интернациональная рамка жанра. Наша полоса — её русская электронная ветка.
