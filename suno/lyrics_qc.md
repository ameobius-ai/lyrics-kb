# Lyrics QC Checklist (13-point)

> Source: bitwize-music-studio/claude-ai-music-skills quality gates
> Adapted for our anti-AI-marker pipeline

## Когда использовать

Перед отправкой лирики в Suno (chirp_generate). Каждый пункт = pass/fail.

## 13 пунктов

### Структура
1. **Section tags** — `[Verse]`, `[Chorus]`, `[Bridge]` присутствуют и расставлены логично
2. **Line length consistency** — строки в пределах одной секции ±30% по слогам

### Ритм
3. **Syllable count match** — рифмующиеся строки имеют близкий слоговый счёт (±2)
4. **Rhythmic flow** — при чтении вслух нет спотыканий, естественный ритм

### Рифма
5. **Rhyme scheme consistency** — схема (AABB / ABAB / ABCB) держится в секции
6. **No banal rhymes** — любовь/кровь/вновь, ночь/дочь/прочь, слёзы/грёзы, любить/забыть → красный флаг

### Произношение (Suno-specific)
7. **Pronunciation risks** — слова которые Suno проглотит/исказит: сложные кластеры согласных, длинные составные слова
8. **Phonetic fixes** — проблемные слова заменены на фонетические аналоги или разбиты дефисами

### Содержание
9. **POV consistency** — точка зрения (1-е/2-е/3-е лицо) не скачет внутри секции
10. **Factual accuracy** — если есть факты/даты/имена — проверены
11. **No AI-markers** — проверка по нашему анти-AI списку (вечность/симфония/гармония/путешествие/и т.д.)

### Стиль
12. **Show don't tell** — конкретные образы вместо абстракций. «запах нафталина» > «ностальгия»
13. **Cross-track repetition** — слова/фразы не повторяются из других треков альбома

## Формат проверки

```
 lyrics_qc(text) → {
   pass: bool,
   checks: [{ name, status: "pass"|"fail"|"warn", detail }],
   summary: "12/13 pass, 1 warn"
 }
```

## Что НЕ проверяем

- Тематика/содержание — это творческое решение, не QC
- Длина трека — это структура, не лирика
- Соответствие жанру — это prompts.md / packages
