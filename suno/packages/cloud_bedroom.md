## Negatives

`no screaming, no aggressive rap belt, no stadium crowd ambience, no festival drop, no high-energy rock vocal, no vocal acrobatics`

Осторожно со словами `hype`, `club anthem`, `dancefloor` — уводят в другой жанр.

## Density / arrangement fix

В cloud/lo-fi разреженность ок. Если 808 пропадает: `constant bass groove, 808 stays active during chorus` без `full groove chorus` фестивального типа.

## Mix start

Cloud/bedroom не имеет жёсткого 7-stem пресета. Стартовая философия: якорь-король, bedroom glue.
- anchor (synth pad / 808): -5 dB, C
- vocal: -2 dB, ±0.3 (моно-близость)
- drums: -8 dB, ±0.4 (dusty, не punchy)
- tape/texture: -12 dB, ±0.6

## Master targets

- SoundCloud: -10…-12 LUFS, crest не убивать
- Spotify: -14
- Воздух/haze важнее громкости; sub boost без crest 3

## Fail → fix

| Поломка | Фикс |
|---|---|
| Ушло в drill/агрессию | убрать aggressive; Monotone melodic + lower BPM |
| Слишком «попсовый» gloss | tape, dusty, bedroom, lo-fi 4-track |
| Hard Auto-Tune карикатура | subtle Autotune; не Auto-Tune wave |
| Пустой низ | soft 808 + mono low-end фраза |
