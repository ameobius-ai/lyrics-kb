# Suno Package: Dark Ambient

Готовый релизный пакет. Длинные формы, дроны, без чёткого бита. Не путать с ambient chill и darksynth.

[источник: practice + bitwize dark-ambient adjacent, 2026-07-19]

---

## Profile

| Параметр | Значение |
|---|---|
| BPM | free / 40–70 feel (often beatless) |
| Тональность | drones on D / A / E |
| Вокал | none or distant wordless / spoken fragments |
| Stem-философия | layers of texture |
| Платформа default | Spotify -14 (wide LRA OK) |
| Референсы | Lustmord, Tim Hecker (darker), Raison d'être, Atrium Carceri |

## Style

```
dark ambient, deep drone, sub-harmonic pads, distant industrial reverb, slow evolving texture, no drums, no melody hook, cavernous space, cold atmosphere, sparse field recordings, 50 BPM feel, cinematic dread, instrumental, no vocals, no beat drop
```

## Style compact

```
dark-ambient, deep-drone, no-drums, cavernous, cold, instrumental, sparse
```

## Vocal anchor

- **Default:** instrumental
- Альт.: distant wordless choir, very low in mix
- Альт.: spoken fragment once, heavily reverbed

## Negatives

`no drums, no trap, no melody hook, no pop vocals, no bright pads, no uplifting, no EDM drop`

## Density / arrangement fix

Если появляется бит:
`strictly beatless, no percussion, only drones and textures`

## Mix start

| Стем | дБ | Пан |
|---|---|---|
| sub drone | -4 | C |
| mid pads | -8 | wide |
| noise/field | -10 | L/R |
| impacts | -12 | C |

Master: long LRA 8–15 · peak <-1.5 · don't squash dynamics

## Fail → fix

| Поломка | Фикс |
|---|---|
| Появился бит | no drums / beatless / remove percussion tags |
| Слишком melodic | remove arpeggio / lead; add drone / texture |
| Тишина в стриминге | raise integrated carefully; keep crest |
