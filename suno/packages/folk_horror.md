## Negatives

`no screaming, no shouting, no arena rock vocal, no soaring vocal, no polished radio-ready gloss, no vocal acrobatics`

Избегать в Style слов-убийц «народности→попса»: `uplifting`, `festival`, `happy folk`.

## Density / arrangement fix

Фолк-хоррор может быть разреженным — не форсить `club anthem`. Если пропадает гитара под вокалом: `full instrumental support behind vocals, constant acoustic groove` без `dancefloor`.

## Mix start

Фолк-хоррор не имеет жёсткого 7-stem пресета (см. coldwave для адаптации). Стартовая философия: якорь-король, акустика = клей.
- anchor (акустическая гитара): -6 dB, C
- vocal: -2 dB, ±0.5 (узкая стерео для интимности)
- drone/strings: -8 dB, ±0.6
- percussion: -10 dB, C (если есть)

## Master targets

- Spotify: -14 / peak -1…-2 / crest 10–12
- Bandcamp/garage: допустимы LUFS громче и true peak >0 только если грязь осознанна (см. `production/mastering.md`)
- Не включать Clarity-пресеты BandLab вслепую — сначала слух на «миф/быт»

## Fail → fix

| Поломка | Фикс |
|---|---|
| Ушло в indie-pop | убрать uplifting/cinematic; добавить tape, drone, dry vocal |
| Визг на «кульминации» | Soft + Mid Register + no soaring |
| Слишком чисто | lo-fi 4-track, vinyl static, plate reverb осторожно |
| Хор съел лид | Choir только behavior на секции, не в Style как lead |
