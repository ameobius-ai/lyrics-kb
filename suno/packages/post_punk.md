# Suno Package: Post-Punk

Готовый релизный пакет. Гитара + бас-пульс + холод. Мост между coldwave и rock.

[источник: practice + bitwize post-punk/darkwave crossover, 2026-07-19]

---

## Profile

| Параметр | Значение |
|---|---|
| BPM | 110–140 (якорь **125**) |
| Тональность | Am / Em / Bm |
| Вокал | baritone, urgent or deadpan |
| Stem-философия | bass-driven |
| Платформа default | Spotify -14 |
| Референсы | Joy Division (ref only), Interpol, Editors, Molchat Doma (adj), She Past Away (adj) |

## Negatives

`no screaming, no metal blast beats, no trap hi-hats, no hyperpop, no bright pop chorus, no jazz chords`

## Density / arrangement fix

`bass stays driving through chorus, drums constant, guitar supports not masks vocal`
