## Negatives

`no clean pop vocals, no bright hi-hats, no cheerful tone, no clear diction, no upbeat tempo, no metal scream, no trap bounce 140+`

## Density / arrangement fix

Если слишком «чисто»:
`more reverb wash, buried vocals, muffled highs, tape saturation, sub drone continuous`

## Mix start

| Стем | дБ | Пан |
|---|---|---|
| vocal | -6 | C (buried) |
| sub | -3 | C |
| drums | -5 | C |
| pads/noise | -7 | wide |

Master: preserve murk — do NOT over-air. HPF only ~30Hz. Crest 8–12 OK.

## Fail → fix

| Поломка | Фикс |
|---|---|
| Слишком понятный вокал | pitch down + reverb + bury −4dB |
| Темп 120+ | force 70–90 BPM |
| Яркий топ | cut HS, add muffled / lo-fi |
| Похоже на phonk | remove cowbell/memphis; add occult / VHS / spectral |
